## 一、项目结论与建设原则

### 1.1 网站定位

SAW ArrayWright官网应被建设为：**SAW光伏阵列智造计划的公开数字总部、真实项目入口、工程进展档案和联合开发平台。**

网站首要服务对象：
- 有真实光伏项目的EPC总包方
- 有真实项目资源的光伏电站业主
- 后续可扩展至支架厂、施工设备厂、机器人公司和设计单位

网站必须同时表达两条同步推进的项目线：
1. **大型光伏电站主线**：SAW的长期主战场与最终价值方向
2. **SAW Carport子项目**：首个公开、可参观、可快速MVP的工程示范场景

两条线共用SAW Core，不能把网站做成普通"光伏车棚公司官网"，也不能把SAW包装成已经拥有成熟整机机器人的设备厂。

### 1.2 首版网站的四个核心任务

1. **讲清愿景**：为机器人重新设计光伏建造
2. **讲清当前能力**：项目评估、场景建模、施工仿真、联合MVP和数据闭环
3. **获得真实项目**：让EPC或业主提交项目资料并进入SAW评估流程
4. **积累网络成熟度**：持续发布可检索、可引用、带版本的工程内容

### 1.3 首版不做什么

- 不开发复杂会员系统
- 不做在线支付或电商功能
- 不包装虚假案例或过度承诺

## 二、网站结构与页面规划

### 2.1 首版页面清单（5个核心页面）

| 页面 | 路径 | 核心目的 |
|------|------|----------|
| 首页 | `/` | 讲清愿景+展示双主线+引导提交项目 |
| 解决方案 | `/solutions` | 展示SAW Core能力+Carport示范 |
| 技术能力 | `/capabilities` | 展示技术栈+工程档案 |
| 项目计划 | `/programs` | 联合开发计划+报名入口 |
| 实验室 | `/lab` | 技术博客+工程日志 |

### 2.2 首页结构（从上到下）

1. **Hero Banner**：全屏视频背景（SAW Banner概念预览视频）+ 核心Slogan
2. **双主线展示**：大型光伏电站 + SAW Carport，左右对比卡片
3. **SAW Core能力概览**：4个核心能力图标+简述
4. **真实项目入口**：醒目的"提交您的项目"CTA按钮
5. **最新动态**：从/lab拉取最新3篇文章
6. **合作伙伴**：天伏能科 × AiToMoney联合发起

### 2.3 解决方案页（/solutions）

分为两个Tab：
- **大型光伏电站**：SAW Core在大型地面电站的应用场景
- **SAW Carport**：车棚场景的MVP示范，含视频/图片展示

每个场景包含：
- 场景描述
- 技术挑战
- SAW解决方案
- 当前进展（进度条或里程碑）

### 2.4 技术能力页（/capabilities）

展示SAW的4大核心能力：
1. **项目评估**：光伏阵列可行性分析
2. **场景建模**：3D场景重建与仿真
3. **施工仿真**：机器人施工路径规划
4. **数据闭环**：施工数据回流与优化

每个能力配：技术原理简述 + 应用场景 + 当前版本状态

### 2.5 项目计划页（/programs）

展示联合开发计划：
- 当前开放的联合MVP项目
- 报名条件和流程
- 已参与伙伴（脱敏展示）

### 2.6 实验室页（/lab）

技术博客/工程日志：
- 文章列表（标题+摘要+日期+标签）
- 文章详情页（Markdown渲染）
- 标签分类

## 三、设计风格要求

### 3.1 整体调性

- **工业科技感**：深色系为主，体现光伏+机器人的硬核属性
- **专业可信**：不浮夸，用数据和事实说话
- **工程档案感**：像技术文档而非营销页面

### 3.2 色彩方案

- 主色：深蓝/深灰（#1a1a2e 或类似）
- 强调色：光伏蓝（#0066cc）或能量橙（#ff6b35）
- 背景：深色渐变或纹理

### 3.3 字体

- 标题：思源黑体 Bold / Inter Bold
- 正文：思源黑体 Regular / Inter Regular
- 代码/数据：等宽字体

### 3.4 视觉元素

- 几何线条、网格背景
- 数据可视化图表
- 真实工程照片/视频（非素材库）
- 技术示意图/流程图

## 四、技术栈要求

### 4.1 前端

- **框架**：Next.js 14+ (App Router)
- **样式**：Tailwind CSS
- **动画**：Framer Motion（Hero视频、页面过渡）
- **部署**：standalone模式，PM2或systemd管理

### 4.2 后端（首版轻量）

- **API路由**：Next.js API Routes
- **表单提交**：存储到SQLite或JSON文件（首版不上数据库）
- **文章管理**：Markdown文件 + 前端渲染

### 4.3 SEO与性能

- 静态生成（SSG）为主
- 结构化数据（JSON-LD）
- 视频懒加载、首屏关键CSS内联
- Lighthouse评分目标：90+

## 五、项目提交表单

### 5.1 表单字段

首版只收集非敏感摘要：
- 姓名、公司、职务、手机、邮箱
- 项目角色：业主、EPC、设计、设备/支架、其他
- 项目类型：大型地面电站、光伏车棚、其他
- 项目所在地、预计规模
- 当前阶段：机会、可研、设计、采购、施工、已完成可复盘
- 是否已有总图、支架图、工序资料
- 简要描述（可选）

### 5.2 提交后流程

1. 前端提交到 `/api/submit-project`
2. 后端存储到 `data/projects/YYYY-MM-DD-xxx.json`
3. 发送通知邮件给SAW团队（首版可省略）
4. 前端显示"已收到，3个工作日内联系"
